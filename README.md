Upload the photos of artwork in the art folder. (click on art folder, then click on Add file in upper right. Make sure to rename the photo according to instructions below)
They MUST be .jpg extention.

Replace the Linkedin API key every two month. (Current -  April 1)

The prompts and secrets are stored in notepad locally.

Each time you add a new image in the folder it must be of the name - artX.jpg where X should be the latest number of artwork.
Also go to Settings> Variables and Secrets> Actions> ART_NUM > Edit>  and replace it with the latest NUMBER X
